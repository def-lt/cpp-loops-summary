# Конспект: Три вида циклов в C++

В C++ есть **три основных вида циклов**: `for`, `while` и `do-while`.

## 1. Цикл `for`
Используется, когда заранее известно количество повторений.

**Синтаксис:**
```cpp
for (инициализация; условие; шаг) {
    // тело цикла
}
```

**Пример:**
```cpp
#include <iostream>
using namespace std;

int main() {
    for (int i = 1; i <= 5; i++) {
        cout << i << " ";
    }
    // Вывод: 1 2 3 4 5
    return 0;
}
```

---

## 2. Цикл `while`
Проверяет условие **перед** выполнением тела. Если условие ложно с самого начала — тело не выполнится ни разу.

**Синтаксис:**
```cpp
while (условие) {
    // тело цикла
}
```

**Пример:**
```cpp
#include <iostream>
using namespace std;

int main() {
    int i = 1;
    while (i <= 5) {
        cout << i << " ";
        i++;
    }
    // Вывод: 1 2 3 4 5
    return 0;
}
```

---

## 3. Цикл `do-while`
Проверяет условие **после** выполнения тела. Тело выполняется **хотя бы один раз**.

**Синтаксис:**
```cpp
do {
    // тело цикла
} while (условие);
```

**Пример:**
```cpp
#include <iostream>
using namespace std;

int main() {
    int i = 1;
    do {
        cout << i << " ";
        i++;
    } while (i <= 5);
    // Вывод: 1 2 3 4 5
    return 0;
}
```

---

## Краткая таблица сравнения

| Цикл       | Когда проверяется условие | Минимум выполнений | Лучше всего подходит для          |
|------------|---------------------------|--------------------|-----------------------------------|
| `for`      | Перед телом               | 0                  | Известное количество повторений   |
| `while`    | Перед телом               | 0                  | Неизвестное количество повторений |
| `do-while` | После тела                | 1                  | Когда нужно выполнить хотя бы раз |

**Полезные операторы:**
- `break` — немедленный выход из цикла
- `continue` — переход к следующей итерации
